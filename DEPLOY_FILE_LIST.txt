==========================================
TỔNG KẾT
==========================================

FOLDERS CẦN ZIP:
1. public/ (chỉ các file đã tạo/sửa)
2. config/
3. routes/
4. cms/Modules/Admin/
5. cms/Modules/Home/Controllers/
6. cms/Modules/Core/Views/
7. cms/Modules/Auth/Views/
8. composer.json (file root)

FILES KHÔNG CẦN:
- .env (sẽ tạo trên server)
- vendor/ (sẽ chạy composer install)
- node_modules/ (sẽ chạy npm install nếu cần)
- storage/ (sẽ tạo trên server)
- .git/ (không cần)
- Các file .md khác (chỉ giữ DEPLOY_CHANGES.md nếu muốn)

==========================================
CÁCH TẠO ZIP
==========================================

Cách 1: Zip từng folder riêng
zip -r deploy.zip public/manifest.json public/sw.js public/pwa-icons/ config/app.php routes/api.php composer.json cms/Modules/Admin/ cms/Modules/Home/Controllers/ cms/Modules/Core/Views/ cms/Modules/Auth/Views/ generate-vapid-keys.php DEPLOY_CHANGES.md

Cách 2: Zip toàn bộ project (loại trừ .env, vendor, node_modules)
zip -r deploy.zip . -x ".env*" "vendor/*" "node_modules/*" ".git/*" "storage/*" "*.log"
